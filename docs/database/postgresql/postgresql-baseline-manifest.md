## Adoption boundary

Production currently requires a separate, explicitly approved metadata adoption operation. This PR must not run `prisma migrate resolve`, `prisma migrate deploy`, or any Production SQL. See `production-baseline-adoption-runbook.md`.

After this PR, the active migration directory is the only executable source of truth:

```text
prisma/migrations/migration_lock.toml
prisma/migrations/20260824000000_postgresql_baseline/migration.sql
```

The legacy archive is documentation-only.
